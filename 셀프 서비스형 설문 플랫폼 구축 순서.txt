셀프 서비스형 설문 플랫폼 구축 순서

사용자(회원) 체계 및 인증 정의플랫폼에 가입하고 로그인하여 설문을 만드는 ‘일반 회원(설문 제작자)’ 시스템을 정의합니다. (이메일/비밀번호 로그인, 소셜 로그인 등)
링크나 QR로 접속하는 ‘응답자’는 별도의 회원가입 없이 익명으로 참여

데이터 모델링(스키마) 확장Users (회원): user_id (PK), email, password_hash, created_at (설문을 만들고 결과를 보는 주체)Surveys (설문지): survey_id (PK), user_id (FK - 누가 만들었는지 연결), title, description, is_active (설문 마감 여부), created_atQuestions (문항): question_id (PK), survey_id (FK), question_type, content, options 등Responses (응답): response_id (PK), survey_id (FK), answers (제출된 답변 내용), submitted_at

핵심 기능 및 API 경로 설계

설문 제작 영역 (로그인 필요):설문 생성: POST /api/surveys (제목, 문항 등을 입력해 새 설문 생성 $\rightarrow$ survey_id 발급)내 설문 관리 및 결과 조회: GET /api/users/me/surveys 또는 GET /api/surveys/{survey_id}/responses (자기가 만든 설문만 조회 가능하도록 권한 체크 필수)

설문 공유 영역 (인증 불필요):링크/QR 생성: survey_id를 기반으로 고유 URL(예: /s/abc123xyz) 생성 및 QR 코드 이미지 렌더링 기능.설문 참여 영역 (인증 불필요):설문 정보 로드: GET /api/public/surveys/{survey_id}

설문 제출: POST /api/public/surveys/{survey_id}/responses화면(UI) 흐름 설계대시보드(마이페이지): 로그인한 사용자가 자신이 만든 설문 목록을 보고, 각 설문의 ‘링크 복사하기’, ‘QR 코드 다운로드’, ‘결과 보기(통계/목록)’ 버튼을 누를 수 있는 화면

.설문 빌더 페이지: 사용자가 직접 문항을 추가하고 수정하여 설문을 완성하는 화면.응답 페이지: 대상자가 링크나 QR을 통해 들어와 문제를 풀고 제출하는 모바일/PC 최적화 화면.결과 리포트 페이지: 제작자가 수집된 응답 데이터를 표나 차트 형태로 확인하는 화면.
